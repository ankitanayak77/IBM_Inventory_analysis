Security & Privacy Summary

Portfolio authentication policies and boundary guarantees

Role-Based Access Control: User operational roles are verified server-side on every request via cryptographic sessions and route guards. Users cannot elevate their own permissions or modify another user's identity.

Email Identity: Email addresses function as unique account usernames within this system. In this local deployment, account credentials are stored in SQLite and do not transmit outbound email.

Password Storage: All passwords are encrypted using scrypt with random salt generation. Plaintext passwords are never logged, flashed, or stored in plaintext.
